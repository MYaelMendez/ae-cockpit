# $æ invocation grammar

**$@ae** is an application-level shorthand in this repository, **not a registered global ChatGPT command**.

- `$@ae` — cockpit
- `$@ae 📧$æ` — email widget
- `$@ae github` — GitHub widget
- `$ae` — ASCII-compatible skill identifier
- `$æ` — display notation
- `$_a_e://` — proposed address notation; no system-wide protocol handler is registered

Every 🛸 is a widget, not the agent or the model inside it.

Widget = UI + Capability + State + Permissions + Evidence.

The current browser prototype only selects widgets and shows connection status. It does not read email, authenticate accounts, run models, send messages, make purchases, or dispatch tools.

A future provider adapter must verify identity, capability, authorization, external effects, and witness receipts before claiming a widget is connected.
