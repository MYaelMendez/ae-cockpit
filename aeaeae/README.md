# $æææ · The chats within the chat

![Three conversations inside one chat](assets/chat-aeaeae.png)

> `>_æææ://` — Many conversations. One principal.

**$æææ** is a human-governed conversation environment: one parent conversation can hold bounded child conversations, each with a purpose, context, task state, and returned evidence.

`aeaeae` is the portable repository name. `$æææ`, `>_æææ://`, and `💬://` are conceptual entry notation; they are not registered platform commands or network protocols.

## Start here

Open [index.html](index.html) in a browser for the self-contained vertical **12-second WebGL origin loop**. No installation, API key, or external service is required. Pause, replay, or scrub the animation. Reduced-motion preferences start playback paused.

**Conversation → intent → environment → corridor simulation → human approval → evidence → conversation ↺**

The corridor scene is an illustration of the molt.earth proposal. It performs no physical action or travel planning.

## The central rule

**Context may propagate; authority does not.**

A child may receive selected context. Receiving context never grants access to tools, accounts, funds, or the authority to act for the human. Proposed consequential actions return to the principal for authorization through a real host permission mechanism.

## What is operational

The local animation, launcher, and [primitive workshop](workbench.html) are implemented. The [local reference runtime](PRIMITIVES.md) supports bounded nested tasks, explicit context selection, local confirmations, two deterministic text capabilities, cancellation, rejoining and hash-linked records. These are task records, not independent LLM conversations. Remote delegation, durable storage, real identity, external grants and live provider tools remain unimplemented.

Run `node --test tests/aeaeae.test.mjs tests/primitives.test.mjs` or `node aeaeae/demo.mjs` from the repository root. Serve the repository locally or over HTTPS to open the workshop. Web Crypto is used where available, with a tested portable SHA-256 implementation for development HTTP origins.
